# آزما — سامانه ثبت‌نام دوره‌ها و فروش محصولات

وب‌سایت فارسی و راست‌چین برای معرفی و ثبت‌نام دوره‌های آموزشی و فروش محصولات، با پرداخت آنلاین از طریق **زرین‌پال** و پنل مدیریت کامل.

- **فناوری:** ASP.NET Core / Blazor Web App روی .NET 10، Entity Framework Core 10، SQL Server، ASP.NET Core Identity
- **رابط کاربری:** Bootstrap 5 RTL، فونت Vazirmatn، آیکون‌های Bootstrap Icons (همه به صورت محلی، بدون CDN)
- **معماری:** لایه‌ای (Domain / Application / Infrastructure / Web)

## امکانات

**بخش عمومی**
- صفحه اصلی: معرفی، دوره‌های فعال و ویژه، محصولات، مدرسین، مزیت‌ها، پرسش‌های متداول، اطلاعات و فرم تماس
- فهرست دوره‌ها با جست‌وجو، دسته‌بندی و فیلتر (ثبت‌نام باز / در حال برگزاری / آینده) و نمایش ظرفیت باقی‌مانده
- صفحه اختصاصی هر دوره: گالری، سرفصل‌ها، مدرس، تاریخ‌ها، روز و ساعت برگزاری، نوع برگزاری، آدرس، ظرفیت، پیش‌نیازها، تخفیف، شرایط و دکمه «ثبت‌نام و پرداخت»
- فهرست و صفحه جزئیات محصولات (فیزیکی و دیجیتال) با کنترل موجودی
- فرم ثبت‌نام کوتاه + فیلدهای اختصاصی قابل تعریف برای هر دوره
- پرداخت زرین‌پال، صفحه نتیجه پرداخت با کد پیگیری، تلاش مجدد برای پرداخت ناموفق، پیگیری سفارش با شماره سفارش و موبایل

**پنل مدیریت** (`/admin`)
- داشبورد آماری، آخرین ثبت‌نام‌ها و تراکنش‌ها
- مدیریت کامل دوره‌ها (اطلاعات، قیمت و تخفیف، ظرفیت، بازه ثبت‌نام، زمان‌بندی، تصاویر، فیلدهای فرم ثبت‌نام، انتشار/پیش‌نویس/بایگانی)
- مدیریت محصولات، دسته‌بندی‌ها، مدرسین، محتوای صفحه اصلی و پرسش‌های متداول
- فهرست ثبت‌نام‌ها و سفارش‌ها با جست‌وجو، فیلتر تاریخ شمسی و **خروجی Excel**
- جزئیات سفارش، سوابق تراکنش، تاریخچه وضعیت، **استعلام مجدد تراکنش‌های نامشخص**، یادداشت مدیریتی و لغو سفارش با ثبت دلیل
- تنظیمات سایت (نام، لوگو، تماس، شبکه‌های اجتماعی، درباره ما، فوتر، درگاه پرداخت)
- مدیریت کاربران مدیر و **گزارش کامل عملیات مدیریتی** (Audit Log)

## ساختار پروژه

```
src/
  Azma.Domain/          موجودیت‌ها و قوانین دامنه (قیمت نهایی، وضعیت ثبت‌نام، ظرفیت)
  Azma.Application/     سرویس‌ها: کاتالوگ، ثبت سفارش، پرداخت، پنل مدیریت؛ اینترفیس‌ها
  Azma.Infrastructure/  EF Core و SQL Server، Migrations، Identity، ماژول زرین‌پال، فایل، Excel
  Azma.Web/             Blazor Web App: صفحات عمومی (SSR) و پنل مدیریت (Interactive Server)
tests/
  Azma.Tests/           تست‌های خودکار (جریان پرداخت، ظرفیت، تخفیف، تاریخ شمسی، پاسخ زرین‌پال)
database/
  AzmaDb.sql            اسکریپت کامل و idempotent ساخت دیتابیس
  backup.sql            اسکریپت پشتیبان‌گیری
docs/                   راهنمای نصب، انتشار، زرین‌پال و معماری
```

## راه‌اندازی سریع (محیط توسعه)

پیش‌نیازها: .NET SDK 10 و SQL Server (LocalDB، Express یا Docker).

```bash
git clone https://github.com/sajad-dehghani/shopping.git
```

```bash
cd shopping/src/Azma.Web
```

حساب مدیر اول را با user-secrets تعریف کنید (در سورس کد ذخیره نمی‌شود):

```bash
dotnet user-secrets set "AdminSeed:Email" "admin@example.com"
```

```bash
dotnet user-secrets set "AdminSeed:Password" "YourStrong@Pass1"
```

اگر از LocalDB استفاده نمی‌کنید، رشته اتصال را هم تنظیم کنید:

```bash
dotnet user-secrets set "ConnectionStrings:DefaultConnection" "Server=localhost,1433;Database=AzmaDb;User Id=sa;Password=...;TrustServerCertificate=True"
```

```bash
dotnet run
```

در اولین اجرا دیتابیس ساخته می‌شود (Migration خودکار)، نقش و کاربر مدیر ایجاد می‌شود و در محیط Development **داده‌های نمونه** (دوره، محصول، مدرس، پرسش متداول) هم اضافه می‌شوند.

- سایت: `https://localhost:7057`
- پنل مدیریت: `https://localhost:7057/admin`

در محیط Development، درگاه در حالت **Sandbox** زرین‌پال است و پرداخت واقعی انجام نمی‌شود.
